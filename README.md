# LABA1 — Управление доставкой (вариант 16)

Этот архив содержит ваш исходный проект LABA1 с доработками по
лабораторным работам №4–6, плюс отдельный тестовый проект.

## Что изменено по сравнению с вашим исходным кодом

### LABA1/DeliveryForm.cs (лаб. №4 — исправление ошибок)
- Кнопки **"Удалить"** и **"Обновить статус"** раньше не работали: код
  восстанавливал адрес доставки, разбирая текст элемента списка
  ("Клиент - Адрес (Статус)"), но не отделял суффикс "(Статус)", из-за
  чего `Deliveries.Find(...)` никогда не находил совпадение. Исправлено:
  теперь используется `deliveriesListBox.SelectedIndex` напрямую.
- Добавлено явное соответствие текста `statusComboBox` ("В пути") и
  имени значения перечисления `DeliveryStatus.В_пути` (с подчёркиванием) —
  раньше `Enum.Parse` мог бы упасть при выборе статуса "В пути".
- Добавлена проверка даты доставки в `AddDeliveryButton_Click`: дата
  в прошлом теперь отклоняется с сообщением об ошибке.

### LABA1/DeliveryForm.cs (лаб. №5 — новая функция)
- Добавлена кнопка **"Редактировать"** и обработчик `EditDeliveryButton_Click`.
- Добавлено предзаполнение полей при выборе доставки в списке
  (`DeliveriesListBox_SelectedIndexChanged`).

### LABA1/DeliveryForm.cs (лаб. №6 — подготовка к UI-автоматизации)
- Всем элементам управления присвоено свойство `Name` (например,
  `customerNameTextBox`, `addDeliveryButton`) — без этого FlaUI не может
  найти элементы по `AutomationId`. Это не меняет функциональность формы.

### LABA1/DeliveryManager.cs
- Добавлен публичный метод `Save()` — обёртка над приватным
  `SaveDeliveries()`, нужна форме, чтобы сохранить изменения,
  внесённые напрямую в объект `Delivery` при редактировании.

### LABA1.Tests/ (новый проект, лаб. №2 и №5)
Тестовый проект MSTest со ссылкой на основной проект:
- `DeliveryTests.cs` — тесты класса `Delivery`.
- `DeliveryManagerTests.cs` — тесты класса `DeliveryManager`, включая
  тест метода `Save()`.
- `BoundaryConditionTests.cs` — граничные случаи.
- `UITests.cs` — проверка наличия и состояния элементов формы.
- `EditDeliveryTests.cs` — тесты новой функции редактирования (лаб. №5).

## Важно: что НЕ было проверено в этой песочнице

Эта работа выполнялась в Linux-песочнице без доступа к NuGet и без
Windows, поэтому:
- `LABA1/Delivery.cs` и `LABA1/DeliveryManager.cs` (включая добавленный
  `Save()`) были реально скомпилированы здесь (`dotnet build`, .NET 8,
  офлайн) — ошибок нет.
- `LABA1/DeliveryForm.cs` **не удалось скомпилировать** в песочнице,
  так как для `net10.0-windows` + WinForms требуется пакет
  `Microsoft.WindowsDesktop.App.Ref` с nuget.org, а сеть песочницы его
  не пропускает. Код проверен вручную (баланс скобок, точные сигнатуры
  методов и полей, совпадающие с вашим оригиналом) — но собрать
  проект и прогнать тесты в Visual Studio на своей машине всё равно
  стоит перед сдачей.
- `LABA1.Tests` не собирался (тот же повод — MSTest NuGet-пакеты
  недоступны офлайн).

Файлы для лабораторной №6 (FlaUI UI-тесты) в данном архиве не
включены как отдельный проект — код примера остался в тексте отчёта
лаб. №6 (Word-документ), так как для него дополнительно нужен собранный
.exe вашего приложения, который в этой песочнице получить нельзя.
